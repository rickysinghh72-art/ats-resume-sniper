### How to Install in Chrome or Edge (Takes 60 Seconds)
1. Click **`ats-resume-sniper.zip`** under **Assets** below to download.
2. **Extract (Unzip)** the downloaded file into a normal folder (for example, `C:\ats-resume-sniper`).
3. Open Chrome and type `chrome://extensions` in the address bar (or `edge://extensions` in Edge).
4. Turn **Developer mode** ON (top right), click **Load unpacked**, and select the extracted folder.
5. Pin **ATS Resume Sniper** to your toolbar, click it on any LinkedIn, Indeed, or Naukri job post, paste your free Gemini API key (from `aistudio.google.com`) + your master resume, and click **Snipe**.

*Privacy Note: Your API key and resume stay 100% locally in your browser storage—zero third-party servers.*
